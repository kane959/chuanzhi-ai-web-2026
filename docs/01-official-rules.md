# 官方赛道信息（2026-10-27 抓取）

## 已核实事实

- 比赛：**2026 第九届传智杯全国大学生数智创新与 AI 应用大赛**。
- 赛道：**AI WEB 网页开发挑战赛**，赛道 ID `10037`，比赛 ID `10003`。
- 官方主题：**“智启未来：AI 驱动的 Web 应用创新挑战”**。
- 形式：作品题；每队 1–3 名来自同一所学校的学生，可配不超过 2 名指导老师。
- 报名/省赛作品指导提交截止：**2026-11-18**。按客户端日期 2026-10-27 计算，距离截止还有 22 天。
- 省赛一、二、三等奖晋级全国总决赛；官方页面列出的省赛比例上限为 10% / 20% / 30%，实际比例由组委会按报名和评审情况调整。
- 代码仓库：GitHub / Gitee，公开或给评审访问权限；需要 README、环境变量模板、依赖说明和真实 Git 提交历史。
- 演示视频：MP4，5–8 分钟，分辨率不低于 1080p，普通话讲解，可配字幕。
- 技术文档：PDF，不超过 30 页，需包含项目概述、需求、架构、AI 技术方案、核心实现、测试部署、总结展望，以及 AI 选型/集成/优化和创新点说明。
- 在线演示：可公网访问、评审期间保持可用、如需登录提供评审账号，属于可选加分项。
- 安全提交：API Key 不能进公开仓库，使用环境变量；提交后不要再修改材料，缺项会影响评审。

## 评审权重

| 维度 | 权重 | 我们的验收证据 |
|---|---:|---|
| AI 技术深度 | 35% | LLM 结构化输出、Agent 计划/工具调用、RAG 引用、多模态输入、安全与降级；有可重复测试记录 |
| 创新性 | 25% | 特定校园行动场景、时空/材料约束规划、过程可视化和人类审批交互 |
| 前端工程质量 | 10% | TypeScript 严格模式、组件化、状态与事件协议、性能预算、CI 和 E2E |
| 实用性 | 10% | 真实新生办事任务；步骤、材料、截止时间和冲突可执行 |
| 用户体验 | 10% | 流式状态、证据跳转、移动端适配、可访问性、错误和空状态 |
| 社会价值与商业潜力 | 10% | 降低校园信息差，数据可迁移到其他学校，支持 B 端知识包和私有化部署 |

AI 技术深度内部拆分为：LLM 集成 8%、Agent/工作流 8%、RAG 6%、多模态 5%、安全/可控 4%、MCP/工具集成 4%。产品验收必须让评委能在演示中看到这些能力的对应证据。

## 命题范围如何转为策略

官方允许自拟与 AI Web 相关选题，但明确要求 AI 是核心能力，不是给传统网页附加一个聊天框。推荐方向覆盖 Agent、RAG、多模态、教育、数据分析、安全治理等。我们选择“校园行动 OS”作为入口，把 RAG、Agent、多模态和工具调用放在同一个真实任务闭环里，避免做单功能聊天机器人。

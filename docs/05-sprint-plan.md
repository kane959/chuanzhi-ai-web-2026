# 22 天省赛冲刺排期（2026-10-27 → 2026-11-18）

## 阶段一：定题和可演示闭环（10-27～10-30）

- 固化产品名、队员/指导教师、参赛组别和学校知识包边界。
- 建立 20 条合成校园资料：通知、办事指南、开放时间、地图点位、材料模板；每条带来源 ID 和更新时间。
- 完成输入 → 检索 → 结构化计划 → 证据卡 → 演示模式的纵向切片。
- 建立 `traceId`、事件协议和失败/无 Key 降级。

验收：评委不用 API Key，5 分钟内能走通一个完整任务；所有输出都能点回原文。

## 阶段二：AI 深度和差异化（10-31～11-05）

- 接入真实 OpenAI 兼容模型；实现严格 JSON 输出、计划-执行映射和 Reviewer。
- 增加图片/PDF 输入；做 PII 提示、截图解析和原文锚点。
- 增加日历冲突、开放时间、材料完整性三个只读工具；实现工具参数校验。
- 完成“情景推演”交互：改日期/空闲时间，计划重新计算且旧计划可回滚。

验收：固定测试集至少 15 条；记录证据召回、计划有效率、工具成功率、无依据拒答率。

## 阶段三：工程、体验和部署（11-06～11-10）

- 组件化重构、移动端适配、键盘导航、错误边界、空状态和加载状态。
- Playwright 走查：首屏、导入、问答、证据跳转、工具失败、审批、导出。
- 发布在线演示；配置健康检查和日志，不把共享密钥放到前端。
- 做一次安全/隐私审计和依赖许可证清单。

验收：CI 通过；在线地址从无痕浏览器可访问；演示模式和真实模式行为一致。

- 截止前至少 24 小时完成材料校验和上传，保留上传回执。

- 每天只合并一个可演示切片，先写验收条件再写实现。
- 每个 AI 功能同时保留成功、无依据、超时、模型不可用四条路径。
- 重要决策写进 `docs/decision-log.md`；不补造不存在的历史。

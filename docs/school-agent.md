# 学校搜索 Agent：实现与验证（2026-11-10）

入口：工作台第一步“告诉我你的学校”。输入学校全称 → 获取搜索候选 → 用户确认官网 → 最多抓取三个同源公开页面 → 加入当前会话资料库。已有关键词检索可以召回这些摘要；不等于模型已根据官网动态生成新任务。

接口：POST /api/school。search 操作接受 schoolName；crawl 操作接受 url。本地 Node 和 Vercel 使用同一实现。

当前范围：HTTPS edu.cn 网站；首页及链接文字含通知、公告、学生、教务、办事等词的同源页面。不覆盖整个网站，不抓登录页、跨域部门站、PDF 或脚本动态正文。页面抓取日期不冒充通知发布日期。搜索结果是候选，不能据标题和域名单独认定官方身份。

验证：固定测试覆盖候选过滤、域名和协议限制、三页上限、站外链接排除、单页失败及事件记录；生产构建通过。真实搜索广州航海学院返回 www.gzmtu.edu.cn 和 www7.gzmtu.edu.cn 候选。本机 DNS 将官网解析到私网地址，正文抓取被拒绝，因此该校真实采集未通过，未部署或冻结提交。

部署要求：前端 VITE_API_BASE_URL 指向后端；全栈部署设为 /。后端需要能访问搜索源和学校公网域名。当前搜索适配使用 Bing RSS，服务可用性和使用条款需在公开部署前复核；不能把此接口当作有保障的商业搜索 API。未配置长期资料存储，导入结果仅保留当前页面会话。

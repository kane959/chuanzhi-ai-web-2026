# 音逢｜中日谐音文化小志

## AI 音频：apiz MiniMax（公众访问）

结果区通过 `/api/audio` 提交与查询异步任务，失败时明确提示并回退浏览器朗读。代理默认关闭，配置 `AI_AUDIO_ENABLED=true` 后访客无需账号即可合成。规则写入仍需要 `admin` 角色。每次最多 200 个假名字符（含空格）；同一网络 IP 每滚动 60 秒最多 3 次，全站北京时间每天最多 1,000 次；使用 Blobs 原子条件写入限制并发计数。失败或结果不明确的提交保守计入额度，同一请求重试不重复计数。每日上限是次数保护，不是精确金额保证。

接口固定使用 `https://api.apiz.ai`、`minimax/t2a`、`speech-2.8-hd`，`language_boost: Japanese`、`speed: 1`、`emotion: calm`。生产环境通过 `AI_AUDIO_VOICE_ID=Japanese_CalmLady` 选择日语女声。密钥仅放 Netlify 环境变量 `APIZ_API_KEY`，不要写入文件或仓库。密钥由他人提供时，应确认公开网站用途和费用承担方。IP 从 Netlify 函数上下文取得并加盐摘要，不保存原始 IP；访客随机令牌用于隔离音频任务，不授权编辑规则。

每 5 秒查任务，前端最长等 5 分钟；单次函数调用不长时间轮询。任务记录和六个共享占位存在 `otowai-audio-jobs` Blobs store，以 API key 的不可逆摘要隔离。使用 [Netlify 条件写入](https://docs.netlify.com/build/data-and-storage/netlify-blobs/) 防止重复创建和超过本网站的 6 个未完成任务。此限制不覆盖其他网站/脚本对同一 key 的使用，建议专用 key。429 可等待重试；网络错误/超时的创建结果不明确时绝不自动重建。浏览器清空/关闭只停止查询，不能取消已提交的付费任务。

未知提交结果或无人查询的任务会保留占位，以免仍在运行时超出并发。管理员须先在 apiz 后台确认任务已结束，再维护对应 Blobs 占位；不要直接清空任务库或轮换 key 绕过限制。完成后的 MP3 保存于私有 `otowai-audio-jobs` store；保存失败可查询原任务重试，不重新合成。音频下载只接受 HTTPS 公网 IPv4、不跟随重定向，最大 4 MiB。旧音频没有自动清理，仍需维护，可能产生平台存储用量。

## 未知字与规则备份

普通生成使用确定性字库规则；已知拼音优先复用手写假名。缺失读音显示“待校对”，不随机生成、不写入正式库，并暂停整句音频。历史记录按当前规则重新生成。历史上已经保存的错误规则无法可靠区分是否为手写，保留并由管理员校对。

管理端提供 JSON 导出/导入恢复，保留 `manual` 等元数据。导入校验格式和同拼音冲突，确认覆盖前下载当前备份；文件只应保存在可信位置。恢复先写入本地，再尝试现有线上同步，失败时明确提示。备份不含 API 密钥或账户凭证。

AI 下载保存原速 Blob，播放滑条不会改变下载文件。分享只使用已生成的音频，不单独发起生成。接口开启后，点击朗读/保存会向配置的第三方服务发送假名文本；应同步更新隐私说明。验证命令：`node scripts/build-static.mjs && node --test tests/*.test.mjs`。

> 在声音里，遇见另一种语言。

“音逢”是一个面向中日语言爱好者的互动网页项目。它不把中文翻译成日文，而是根据汉字拼音与日语假名的相近读音，生成可朗读的日语“空耳”表达，让使用者从声音角度重新观察汉字、假名与文化传播。

在线体验：[https://otowai-sound-encounters.netlify.app/](https://otowai-sound-encounters.netlify.app/)

代码仓库：[https://github.com/tths1/otowai-sound-encounters](https://github.com/tths1/otowai-sound-encounters)

## 项目亮点

- **空耳制造器**：输入中文、日文或混合词句，按逐字音感规则生成假名与发音。
- **非意译设计**：生成过程只处理读音相近性，不把“我”翻译成“わたし”等语义对应。
- **同音字复用**：相同拼音的汉字自动归入同一规则，输出更稳定，也便于持续校对。
- **朗读时长匹配**：首次朗读会静音测量中文原句和生成假名的语音时长，自动调整假名朗读语速，使两者节奏接近；用户仍可微调速度。
- **可检索词集与历史**：支持搜索已有词条，保存本机最近生成记录。
- **可维护的规则库**：管理者可更新拼音—假名映射；公共页面不显示编辑区。
- **响应式与深色模式**：适配电脑、手机浏览，并尊重减少动效偏好。

## 技术方案

| 模块 | 实现方式 |
| --- | --- |
| 前端页面 | HTML5、CSS3、原生 JavaScript |
| 音感生成 | 拼音映射表 + 同音字复用 + 未命中字的音节簇回退 |
| 浏览器朗读 | Web Speech API（`SpeechSynthesisUtterance`） |
| 时长匹配 | 静音实测中文和假名基准时长，按 `假名时长 / 中文时长` 自动换算朗读语速 |
| 本地状态 | `localStorage` 保存主题、历史和本地草稿 |
| 在线部署 | Netlify 静态托管 + Functions |
| 规则服务 | Netlify Functions、Netlify Blobs；写入接口需管理员身份 |

## 本地运行

项目可直接以静态站点方式预览：

```bash
node scripts/build-static.mjs
python3 -m http.server 4174 --bind 127.0.0.1 --directory dist/client
```

然后打开 `http://127.0.0.1:4174/`。

如需同时调试 Netlify Functions，请先安装依赖并使用 Netlify 开发环境。

## AI 使用说明

本作品将 AI 用于需求分析、方案设计、代码审查和测试用例设计；访客实际使用时不调用在线大模型，也不会上传输入内容。空耳生成由本项目的可校对拼音—假名规则引擎完成。完整过程见 [AI 辅助开发记录](docs/AI辅助开发记录.md)。

## 使用边界

本项目的“空耳”属于语言游戏和声音联想，不用于证明中文、日文读音存在严格的一一历史对应关系。词库会持续校对和扩充。
